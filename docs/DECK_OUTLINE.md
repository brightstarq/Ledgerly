# 10-minute deck outline (8 slides)
1. **Problem (1 min):** US$5.7T MSME finance gap (+US$2.1T informal). Healthy cash flow, no collateral or history.
2. **Insight (1 min):** Most tools serve lenders. Ledgerly serves the borrower: "AI as a financial participant."
3. **Demo story (2 min):** Lagos fabric trader; December stock-up; downside forecast shows a cash dip below buffer.
4. **How it works (1.5 min):** ingest -> passport -> forecast -> alerts -> match -> pack -> approval -> sandbox.
5. **Explainability and fairness (1 min):** factor explanations, no protected attributes, disparate-impact monitor.
6. **Security (1.5 min):** tiers, approval gate, consent, injection screening, audit chain. Show tamper test.
7. **Evidence (1 min):** 24 tests, sandbox log, audit log.
8. **Roadmap and impact (1 min):** real mobile-money adapters, calibration with lender partners, local languages.
